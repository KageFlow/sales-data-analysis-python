# Dataset

`sales_data.csv` is a small **synthetic demo dataset** created to test the notebook. It does not represent actual customers, transactions, or a real business.

For a real analysis, use a dataset you are allowed to use and record its name, source URL, license/usage terms, and download date here. The notebook expects columns equivalent to:
- `Order Date`
- `Product`
- `Quantity`
- `Unit Price`
- `City`

An optional `Order ID` column enables distinct-order counting.
